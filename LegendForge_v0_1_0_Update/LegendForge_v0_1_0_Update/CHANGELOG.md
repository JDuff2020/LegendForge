# Changelog

## 0.1.0 — Foundation

### Added
- LegendForge application identity and versioning.
- File, Edit, View, Tools, and Help menus.
- Main toolbar and keyboard shortcuts.
- Dockable Recent Projects and Session Notes panels.
- Recent-project history with one-click reopening.
- Persistent window geometry and dock layout.
- Settings dialog for theme, startup restore, and recent-project limit.
- System, light, and dark appearance modes.
- About dialog.
- Safer atomic settings-file writes.

### Retained
- Project creation, opening, and saving.
- Artwork-library scanning.
- Inventory-workbook profiling.
- Dynamic MPC pricing-workbook loading.
- Background project validation and logging.
