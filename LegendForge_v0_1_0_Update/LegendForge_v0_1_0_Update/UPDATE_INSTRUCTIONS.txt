working D:\MPCB folder.

INSTALL INTO YOUR GITHUB REPOSITORY
-----------------------------------
1. Open this update ZIP.
2. Copy every file and folder into the root of your local repository.
3. Allow Windows to replace the three existing files listed above.
4. Do not copy your .venv folder into GitHub.

INSTALL INTO D:\MPCB
--------------------
Copy the same update contents into D:\MPCB and allow replacement.
Your existing virtual environment and DeckPrices.xlsx can remain unchanged.

RUN
---
Double-click RUN_BUILDER.bat, or run:

    .venv\Scripts\python.exe main.py

QUICK TEST
----------
Confirm that the app opens with:
- LegendForge 0.1.0 in the title bar
- File/Edit/View/Tools/Help menus
- a toolbar
- Recent Projects and Session Notes dock panels
- Settings and About dialogs
